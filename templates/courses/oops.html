Classes and Objects

What are Classes and Objects?

A class is a blueprint for creating objects, defining their properties (attributes) and behaviors (methods). An object is an instance of a class, representing a specific entity with the defined properties and behaviors.

  • Class: Template with fields (data) and methods (functions).
  • Object: Instance created from the class using the new keyword.

Declaring a Class in Java

In Java, a class is declared using the class keyword, followed by fields and methods.

Syntax:

class ClassName {
    // Fields (attributes)
    dataType fieldName;
    // Methods
    returnType methodName(parameters) {
        // Method body
    }
}

Example:

class Car {
    String model; // Field
    int year;
    // Constructor
    Car(String model, int year) {
        this.model = model;
        this.year = year;
    }
    // Method
    void displayInfo() {
        System.out.println("Model: " + model + ", Year: " + year);
    }
}

Creating Objects in Java

Objects are created from a class using the new keyword, typically via a constructor.

Example:

public class Main {
    public static void main(String[] args) {
        Car myCar = new Car("Toyota", 2020); // Create object
        myCar.displayInfo(); // Prints: Model: Toyota, Year: 2020
    }
}

Uses of Classes and Objects

  • Modeling Entities: Represent real-world objects like cars, students, or accounts.
  • Code Organization: Group related data and functions for modularity.
  • Reusability: Create multiple objects from one class blueprint.
  • Data Management: Store and manipulate object-specific data.

Additional Notes

  • Constructors: Special methods to initialize objects; default constructor has no parameters.
  • this Keyword: Refers to the current object, used to distinguish fields from parameters.
  • Best Practices: Use meaningful class names, initialize fields properly, and avoid complex constructors.
  • Real-World Example: Classes model bank accounts in banking apps or game characters in simulations.

Inheritance

What is Inheritance?

Inheritance allows a class (subclass) to inherit fields and methods from another class (superclass), promoting code reuse and establishing a hierarchical relationship.

  • Superclass: Parent class providing common attributes/methods.
  • Subclass: Child class that extends the superclass.

Implementing Inheritance in Java

Use the extends keyword to inherit a class.

Syntax:

class Superclass {
    // Fields and methods
}
class Subclass extends Superclass {
    // Additional fields and methods
}

Example:

class Vehicle {
    String brand;
    Vehicle(String brand) {
        this.brand = brand;
    }
    void display() {
        System.out.println("Brand: " + brand);
    }
}
class Car extends Vehicle {
    int doors;
    Car(String brand, int doors) {
        super(brand); // Call superclass constructor
        this.doors = doors;
    }
    void displayCar() {
        System.out.println("Brand: " + brand + ", Doors: " + doors);
    }
}
public class Main {
    public static void main(String[] args) {
        Car myCar = new Car("Honda", 4);
        myCar.display(); // Prints: Brand: Honda
        myCar.displayCar(); // Prints: Brand: Honda, Doors: 4
    }
}

Uses of Inheritance

  • Code Reusability: Reuse common code across multiple classes.
  • Hierarchy Modeling: Represent "is-a" relationships (e.g., Car is a Vehicle).
  • Extensibility: Add specific features to subclasses without modifying the superclass.

Additional Notes

  • super Keyword: Access superclass methods or constructors.
  • Single Inheritance: Java supports only single inheritance (one superclass).
  • Limitations: Avoid deep inheritance hierarchies to prevent complexity.
  • Real-World Example: Inheritance is used in GUI frameworks (e.g., buttons extending components) or game entity systems.

Polymorphism

What is Polymorphism?

Polymorphism allows objects of different classes to be treated as objects of a common superclass. It enables one interface to represent multiple forms, achieved through method overriding or overloading.

  • Method Overriding: Subclass provides a specific implementation of a superclass method.
  • Method Overloading: Multiple methods with the same name but different parameters.

Implementing Polymorphism in Java

Use method overriding with inheritance or overloading within a class.

Method Overriding Example:

class Animal {
    void sound() {
        System.out.println("Some sound");
    }
}
class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Woof");
    }
}
public class Main {
    public static void main(String[] args) {
        Animal myDog = new Dog(); // Polymorphic reference
        myDog.sound(); // Prints: Woof
    }
}

Method Overloading Example:

class Calculator {
    int add(int a, int b) {
        return a + b;
    }
    double add(double a, double b) {
        return a + b;
    }
}
public class Main {
    public static void main(String[] args) {
        Calculator calc = new Calculator();
        System.out.println(calc.add(5, 3)); // Prints: 8
        System.out.println(calc.add(5.5, 3.3)); // Prints: 8.8
    }
}

Uses of Polymorphism

  • Flexibility: Write generic code that works with multiple types.
  • Extensibility: Add new subclasses without changing existing code.
  • Interface Design: Define common behavior for different implementations.

Additional Notes

  • Runtime vs. Compile-Time: Overriding is runtime (dynamic) polymorphism; overloading is compile-time (static).
  • @Override Annotation: Ensures method overriding is intentional.
  • Best Practices: Use polymorphism for extensible designs but avoid overcomplicating method hierarchies.
  • Real-World Example: Polymorphism is used in event handling (e.g., different button types) or graphics rendering (shapes with common draw methods).

Encapsulation

What is Encapsulation?

Encapsulation is the bundling of data (fields) and methods that operate on that data within a class, restricting direct access to some components. It’s achieved using access modifiers and getters/setters.

  • Access Modifiers: private, protected, public control visibility.
  • Getters/Setters: Methods to access and modify private fields safely.

Implementing Encapsulation in Java

Use private fields with public getter and setter methods.

Example:

class Person {
    private String name;
    private int age;
    // Constructor
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
    // Getters
    public String getName() {
        return name;
    }
    public int getAge() {
        return age;
    }
    // Setters
    public void setName(String name) {
        this.name = name;
    }
    public void setAge(int age) {
        if (age > 0) this.age = age; // Validation
    }
}
public class Main {
    public static void main(String[] args) {
        Person person = new Person("Alice", 30);
        person.setAge(31); // Valid update
        System.out.println(person.getName() + ": " + person.getAge()); // Prints: Alice: 31
    }
}

Uses of Encapsulation

  • Data Protection: Prevent invalid data with validation in setters.
  • Modularity: Hide implementation details, exposing only necessary interfaces.
  • Maintainability: Change internal logic without affecting external code.

Additional Notes

  • Access Modifiers: private for fields, public for methods, protected for inheritance.
  • Immutable Classes: Use final fields with no setters for immutability.
  • Best Practices: Always validate inputs in setters; avoid exposing fields directly.
  • Real-World Example: Encapsulation is used in database models or user profile management to protect sensitive data.

Abstraction

What is Abstraction?

Abstraction hides complex implementation details and exposes only essential features. It’s achieved using abstract classes or interfaces in Java.

  • Abstract Class: Cannot be instantiated; may contain abstract and concrete methods.
  • Interface: Specifies methods that classes must implement; supports multiple inheritance.

Implementing Abstraction in Java

Use abstract classes or interface keyword.

Abstract Class Example:

abstract class Shape {
    abstract double area(); // Abstract method
    void display() { // Concrete method
        System.out.println("This is a shape");
    }
}
class Circle extends Shape {
    double radius;
    Circle(double radius) {
        this.radius = radius;
    }
    @Override
    double area() {
        return Math.PI * radius * radius;
    }
}

Interface Example:

interface Drawable {
    void draw();
}
class Rectangle implements Drawable {
    double length, width;
    Rectangle(double length, double width) {
        this.length = length;
        this.width = width;
    }
    public void draw() {
        System.out.println("Drawing rectangle with length " + length + ", width " + width);
    }
}
public class Main {
    public static void main(String[] args) {
        Shape circle = new Circle(5);
        System.out.println("Area: " + circle.area()); // Prints: Area: 78.539...
        circle.display(); // Prints: This is a shape
        Drawable rect = new Rectangle(4, 3);
        rect.draw(); // Prints: Drawing rectangle with length 4, width 3
    }
}

Uses of Abstraction

  • Simplified Interfaces: Expose only necessary functionality to users.
  • Extensibility: Define contracts for multiple implementations.
  • Decoupling: Separate interface from implementation details.

Additional Notes

  • Abstract vs. Interface: Use interfaces for multiple inheritance; abstract classes for shared code.
  • Java 8+: Interfaces can have default and static methods.
  • Best Practices: Use abstraction to define clear APIs; avoid over-abstracting simple systems.
  • Real-World Example: Abstraction is used in JDBC drivers (interface-based) or plugin systems (abstract classes).
